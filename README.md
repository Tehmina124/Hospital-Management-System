# 🏥 Hospital Management System

A Python-based Hospital Management System developed using **Object-Oriented Programming (OOP)** and **JSON File Handling** to efficiently manage patients, doctors, appointments, medicines, and billing.

---

## 📌 Overview

This project is a console-based hospital management application that streamlines hospital operations, including patient registration, doctor management, appointment scheduling, billing, and medicine inventory management.

---

## ✨ Features

- 👤 Patient Management (Add, View, Update, Delete, Search)
- 🆔 Automatic Patient ID Generation
- 👨‍⚕️ Doctor Management
- 📅 Appointment Booking & Status Updates
- 💊 Medicine Inventory Management
- 💰 Patient Bill Generation
- 📊 Hospital Report Generation
- 🔐 User Login System
- 💾 JSON-based Data Storage

---

## 🛠️ Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON File Handling

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/Tehmina124/Hospital-Management-System.git
```

2. Navigate to the project folder

```bash
cd Hospital-Management-System
```

3. Run the application

```bash
python hospital.py
```
